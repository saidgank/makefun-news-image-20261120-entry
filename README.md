A broadsheet front page that sums up Friday 20 November 2026 in a single image: the World Court's genocide verdict against Myanmar, the first Trump–Xi–Putin summit in Shenzhen, Russia's overnight strike on Kyiv, the AI sell-off and Anthropic's Nasdaq debut, and Houthi missiles over Riyadh — plus the day's briefs. compose.py (Python + PIL) typesets the page into entry.png; main.py copies that PNG to the output directory, byte for byte, every run.

## Run it

```sh
python3 compose.py  # rebuild entry.png
MAKEFUN_OUTPUT_DIR=out python3 main.py  # write the entry image
```
